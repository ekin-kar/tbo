Is TBO a real strategy, or lucky numbers?

Checks on the 4-coin bot (BTC, ETH, DOGE, ADA), 2020–23 and 2024–26 judged separately. All fees included.

Short answer

Test 1: same rules, random entries

200 runs where only the entry moment is random: same coins, same trend filter, same 1-ATR stop, same breakeven, same 5-day exit, same position sizes. If the real entries were luck, they would sit inside this pile.

Why each rule exists

Test 2: what happens if you change the numbers

Return per unit of drawdown (higher = smoother) for nearby settings, everything else as in the bot. The outlined cell is the bot. If the bot's numbers were a lucky pick, it would be a lone dark cell surrounded by pale ones.
